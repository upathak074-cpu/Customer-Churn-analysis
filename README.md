🔎 Overview
Customer churn is a key challenge for subscription-based businesses. This project explores churn patterns using Python-based Exploratory Data Analysis (EDA) to uncover insights from customer data.

🎯 Objectives
Understand dataset structure & clean data

Analyze overall churn rate (~26.54%)

Compare churn across tenure, contract type, services, payment methods, demographics

Generate business insights via visualizations

🛠️ Tech Stack
Python 🐍

Pandas 🐼

NumPy 🔢

Matplotlib 📊

Seaborn 📈

Jupyter Notebook 📓

📂 Workflow
Raw Data → Cleaning → Transformation → EDA → Visualization → Insights

📌 Key Insights
Tenure: Shorter tenure → higher churn

Contract Type: Month-to-month → highest churn

Payment Method: Electronic check → higher churn

Senior Citizens: Show different churn behavior

Gender: Minimal impact

Services: Certain services linked with churn differences

🚀 Learnings
Data cleaning (missing values, type conversion, duplicates)

Pandas operations (read_csv, groupby, agg, etc.)

Visualization with Matplotlib & Seaborn

Moving from raw data → insights
